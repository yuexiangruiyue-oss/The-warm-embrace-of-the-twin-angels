## 设计原则（贯穿全文）

| 原则 | 含义 | UX 落地 |
|------|------|---------|
| **沉浸优先** | UI 服务于叙事，不打断情感流 | 默认隐藏非必要 UI；对话框为唯一常驻 UI；天使图标最小化 |
| **天使在叙事中而非 UI 中** | 天使是角色不是界面元素 | 天使的存在感通过立绘/台词/翅膀传达，不通过 UI 图标/状态条/HUD 传达；翅膀亮度是视觉叙事不是数值条 |
| **无障碍默认化** | 无障碍不是"额外功能"而是"默认体验" | 首次启动引导玩家确认无障碍设置；光敏性安全默认开启；内容预警默认开启 |
| **进度隐形** | 玩家不应感到"在刷进度" | 不显示 bond_depth 数值；质点完成度以视觉而非数字呈现；无经验值/成就弹窗 |
| **无时间压力** | 没有任何倒计时、QTE、限时选择 | 所有选择无限时；天使介入有延迟但不催促玩家操作；文本速度可完全关闭 |

### 1.3 关键导航规则

| 规则 | 说明 | 设计原则 |
|------|------|---------|
| **无"游戏内退出到桌面"快捷键** | ESC 只打开暂停菜单，不直接退出 | 无时间压力——玩家不应感到"被困住"也不应有"一键退出"的冲动 |
| **暂停菜单始终可访问** | 任何游戏时刻按 ESC/右键均可暂停 | 沉浸优先——暂停不破坏叙事流，只是"暂停时间" |
| **天使介入期间暂停可用** | 天使介入（包括 HARM_GUIDE）期间可暂停但不可跳过 | 无障碍——玩家可在任何时候暂停呼吸 |
| **首次启动强制无障碍引导** | 首次启动必须经过无障碍确认页面 | 无障碍默认化 |
| **章节标题卡后自动显示预警** | 内容预警在标题卡和正文之间 | 情感安全 |
| **图鉴从主菜单进入** | 游戏中不直接进入图鉴（避免破坏沉浸） | 沉浸优先 |
| **结局画面后返回主菜单** | 不自动开始新周目 | 无时间压力——玩家需要消化结局 |

### 2.2 首次启动引导（first_launch）

#### 2.2.1 目的

首次启动时引导玩家进行基础无障碍配置。**这不是可选的**——它是在游戏开始前对玩家的第一次关怀。

#### 2.2.2 流程

```
Step 1: 欢迎页
  "欢迎来到《双生天使的拥抱》。
   这是一个关于痛苦、转化与爱的故事。
   在开始之前，我想先确认一些事情，让你在这里感到安全。"
  [继续]

Step 2: 光敏性安全
  "你是否对闪烁的光线或快速画面变化敏感？"
  ○ 我需要光敏性安全模式（默认选中）
  ○ 我不需要
  
  说明："开启后，画面震动和闪光效果将被替换为更温和的视觉效果。
        你可以随时在设置中修改。"
  [继续]

Step 3: 文字速度
  "你希望文字以什么速度显示？"
  ○ 逐字显示（默认，沉浸感更强）
  ○ 立即显示（适合快速阅读者）
  ○ 自定义速度
  
  [预览框：显示一段示例文字，按所选速度呈现]
  [继续]

Step 4: 内容预警
  "这个故事涉及心理健康主题，包括自我否定、绝望和自我伤害。
   我会在可能触动的章节前提醒你。
   你也可以选择跳过某些特别沉重的段落。"
  ○ 启用内容预警（默认选中）
  ○ 不需要内容预警
  [继续]

Step 5: 自我发声（屏幕阅读器）
  "你是否使用屏幕阅读器？"
  ○ 是的，启用自我发声
  ○ 不需要（默认）
  [继续]

Step 6: 完成
  "谢谢。无论你选择什么，天使都会在你身边。
   准备好了就开始吧。"
  [开始游戏]
```

#### 2.2.3 规格

| 元素 | 规格 |
|------|------|
| 背景 | 深紫藤 #6B5A98 渐变至夜灰蓝 #4A5568 |
| 文字 | 天使白 #FDF8FF，字号 28px（正文）/ 24px（选项） |
| 按钮 | "继续"按钮居中底部，尺寸 200×50px |
| 单选选项 | 圆形指示器+文字，选中时指示器填充暖金 #F5D89A |
| 过渡 | 每步之间 0.5 秒淡入淡出 |
| persistent 标记 | 完成后 `persistent.first_launch = False` |

### 2.3 游戏主画面（game）

游戏主画面是玩家 90% 时间所在的屏幕。它由以下层级组成（从底到顶）：

#### 2.3.1 图层堆叠

```
Layer 5 (top):    UI 覆盖层（选择按钮、暂停提示）
Layer 4:          天使陪伴覆盖层（angel_overlay）
Layer 3:          暗流视觉效果层（动态叠加）
Layer 2:          角色立绘层（天使 + 心爱的 + Sephirot 角色）
Layer 1:          背景层（场景 CG）
Layer 0 (base):   对话框层（底部常驻）
```

#### 2.3.2 对话框

| 属性 | 规格 | 来源 |
|------|------|------|
| 尺寸 | 1920×280px，底部对齐 | 美术圣经 §4.1 |
| 背景（默认） | 半透明深紫藤 #6B5A98，alpha 0.85 | UX 决策（可访问性优先；美术圣经原始规格为浅色 rgba(253,248,255,0.92)，经与 art-director 协商确认深色为默认） |
| 背景（低刺激模式） | 半透明天使白 #FDF8FF，alpha 0.92 | 美术圣经 §4.1 原始规格；低刺激模式下切换为更柔和的浅色对话框 |
| 浅色版文字色 | 深紫藤 #6B5A98 或夜灰蓝 #4A5568（须满足 WCAG AA ≥4.5:1） | UX 决策（浅色背景上不可使用天使白文字，对比度不足） |
| 圆角 | 上沿圆角 20px | — |
| 说话者名字 | 左上角，暖金 #F5D89A，字号 26px，粗体 | 美术圣经 §4.1 |
| 正文文字 | 天使白 #FDF8FF（深色背景）/ 深紫藤 #6B5A98（浅色背景），字号 30px（normal），行高 1.6 | UX 决策（字号经与 art-director 协商确认 30px 为 Normal 基准，四档 24/27/30/34px） |
| 文字区域 | 左边距 80px，右边距 80px（文字区域宽 1760px），上边距 70px | UX 决策 |
| 文字呈现 | 逐字显示（默认），可设为立即显示或自定义速度 | — |
| 点击推进提示 | 对话框右下角小三角形 ▼，呼吸式淡入淡出 | — |
| 暗流期间 | 文字可能抖动/模糊/消失（见 §7 暗流 UX） | 存在保护 GDD §2.1 |
| 天使台词特殊 | 天使台词时，说话者名字旁边显示极小的翅膀图标（16×16px） | — |

#### 2.3.3 天使陪伴覆盖层（angel_overlay）

天使陪伴覆盖层是游戏中唯一的"角色级 UI"——它不显示数值，只显示天使的视觉存在。

| 元素 | 规格 | 来源 |
|------|------|------|
| 天使立绘 | 根据当前情绪状态和翅膀阶段显示对应立绘 | 天使陪伴 GDD §4 |
| 翅膀渲染 | 基础翅膀图 + `matrixcolor` 动态调亮 | 架构文档 §8.3 |
| 天使位置 | 默认画面右侧偏后（"陪伴"位置） | 美术圣经 §3.2 |
| 天使交互热区 | 天使立绘区域可点击（hover 时轻微发光提示） | 天使陪伴 GDD §3.1 |
| 点击冷却 | 点击后 30 秒内不可再次互动（`click_cooldown_until`） | 天使陪伴 GDD §3.2 |
| 拥抱提示 | 当可拥抱时，天使立绘旁出现极淡的暖金光晕（不显示文字） | — |
| 存在模式 | `display`（默认显示）/ `approach`（移动到心爱的身边）/ `voice_only`（仅声音，立绘淡出） | 天使陪伴 GDD §2.1 |
| **不显示的元素** | ❌ 无 bond_depth 数值条；❌ 无信任度仪表；❌ 无"好感度"提示；❌ 无天使状态图标 | 进度隐形原则 |

#### 2.3.4 暗流视觉层

暗流视觉层在暗流触发时动态叠加在角色立绘层之上。详见 §7。

#### 2.3.5 游戏中交互

| 操作 | 效果 | 说明 |
|------|------|------|
| 鼠标左键 / Space / Enter | 推进对话 | 若文字正在逐字显示，第一次点击立即显示全部；第二次点击推进 |
| 鼠标右键 / ESC | 打开暂停菜单 | — |
| 鼠标滚轮上 | 查看历史对话 | Ren'Py 原生 `history` screen |

| Tab | 自动推进模式开关 | 文字显示完后自动推进 |
| H | 隐藏 UI（对话框+覆盖层） | 截图用 |

## 6. 核心系统 UX 流程

### 6.1 选择系统 UX 流程

#### 6.1.1 完整流程

```
叙事到达 choice_node
  │
  ▼
C3.present_choices(node_id) 加载选项
  │
  ├─ C2.filter_choices_by_angel_state() 过滤
  │   └─ 根据天使情绪状态可能隐藏/调整某些选项
  │
  ▼
UI: 选项从下方依次淡入（0.5秒）
  │
  ▼
玩家选择（无限时）
  │
  ├─ 若 NEUTRAL（"询问天使"选项）:
  │   ├─ 天使给出建议（台词）
  │   ├─ 被建议的选项轻微发光
  │   └─ 重新呈现选择（过滤掉已选的 NEUTRAL 选项）
  │
  ├─ 若 ENGAGE:
  │   └─ 叙事跳转到 option.narrative_jump
  │
  ├─ 若 ESCAPE:
  │   ├─ escape_count + 1
  │   ├─ 若 escape_count == 3:
  │   │   ├─ 天使代理流程（见 §4.3.3）
  │   │   └─ 质点 50% 完成
  │   └─ 否则: 叙事跳转到 escape 路径
  │
  ▼
C3.process_selection(option):
  ├─ 更新 bond_depth（+option.bond_depth_delta）
  ├─ 更新 angel_response_profile（+option.angel_response_delta）
  ├─ 若 option.existence_protection:
  │   └─ C5.trigger_undertow(type, intensity)
  ├─ 若 option.confrontation_tag:
  │   └─ C4.process_confrontation(sephirot_id, tag)
  ├─ 记录 memory_entry 到天使记忆库
  └─ C1.narrative_jump(option.narrative_jump)
```

#### 6.1.2 选择 UX 关键点

| 关键点 | UX 处理 | 设计原则 |
|--------|---------|---------|
| 选项不标注"正确/错误" | 无任何视觉标记区分 ENGAGE/ESCAPE | 进度隐形 |
| 无限时 | 玩家可以无限长时间考虑 | 无时间压力 |
| "询问天使"可选 | 玩家可主动寻求帮助，但不强制 | 天使在叙事中 |
| 逃避不惩罚 | ESCAPE 选项的视觉与其他选项完全一致 | 无惩罚 |
| 延迟后果 | 选择的影响通过后续叙事和天使记忆体现，不立即显示数值 | 进度隐形 |

## 7. 暗流/天使介入序列 UX 规格

### 7.1 暗流触发到解除的完整 UX 时间线

```
                 暗流 UX 时间线（以中强度为例）

 t=0s      暗流触发
   │       ├─ 暗流视觉层激活（滤镜/震动/碎裂等）
   │       ├─ 暗流音效激活（心跳/嗡鸣/碎裂声等）
   │       └─ 对话框文字可能受影响（抖动/模糊/消失）
   │
 t=0-5s    情感压迫期（中强度延迟5秒）
   │       └─ 玩家"感受"暗流的压迫
   │          注意：玩家仍可推进对话，暗流叠加在叙事之上
   │
 t=5s      天使介入开始
   │       ├─ 介入类型由暗流类型+强度决定
   │       │   gentle: 天使微笑，浮动文本
   │       │   active: 天使走向心爱的，拥抱动画
   │       │   forceful: 紧急拥抱，翅膀闪光后黯淡，慢速逐字
   │       │   urgent: 瞬间出现在身前，紧紧拥抱，禁用跳过
   │       ├─ 天使台词呈现（对话框）
   │       └─ 暗流视觉开始消退
   │
 t=5-8s    画面恢复过渡
   │       ├─ 滤镜/震动/碎裂逐渐消退
   │       ├─ 音效恢复正常
   │       └─ 文字恢复正常
   │
 t=8-13s   "余震"阶段
   │       ├─ 画面有极轻微的暗流痕迹（如5%灰色滤镜）
   │       └─ 5秒后完全消失
   │
 t=13s     恢复正常
           └─ 叙事继续

 注意：HARM_GUIDE 无延迟（t=0 即介入），恢复最快（2秒）
       高强度暗流延迟8秒，恢复8秒
```

### 7.2 介入类型 UX 规格

#### 7.2.1 gentle（温柔提示）

| 属性 | 规格 | 来源 |
|------|------|------|
| 触发条件 | 低强度（1-3），非 HARM_GUIDE | 存在保护 GDD §2.2.1 |
| 天使表情 | `tender_smile`（温柔微笑） | — |
| 天使移动 | 不移动（保持在原位） | — |
| 台词呈现 | 浮动文本（对话框上方淡入淡出）或正常对话框 | — |
| 翅膀变化 | 无明显变化 | — |
| 跳过 | 可跳过 | — |

#### 7.2.2 active（主动拥抱）

| 属性 | 规格 | 来源 |
|------|------|------|
| 触发条件 | 中强度（4-6），非 HARM_GUIDE | 存在保护 GDD §2.2.1 |
| 天使表情 | `aching`（心疼） | — |
| 天使移动 | 从原位移动到心爱的身边（approach 动画，1秒） | — |
| 拥抱动画 | 天使展开翅膀包裹心爱的（2秒） | — |
| 台词呈现 | 正常对话框，正常速度 | — |
| 翅膀变化 | 轻微暗淡（永久层扣减） | — |
| 跳过 | 可跳过 | — |

#### 7.2.3 forceful（用力拉回）

| 属性 | 规格 | 来源 |
|------|------|------|
| 触发条件 | 高强度（7-10），非 HARM_GUIDE | 存在保护 GDD §2.2.1 |
| 天使表情 | `resolute`（坚定） | — |
| 天使移动 | 快速移动到心爱的身边（0.5秒） | — |
| 拥抱动画 | 紧急拥抱，翅膀闪光后明显黯淡（1秒） | — |
| 台词呈现 | **慢速逐字**（每字 0.05 秒间隔，比正常慢 1.5 倍） | — |
| 翅膀变化 | 明显暗淡（永久层扣减 + 临时层闪光） | — |
| 跳过 | 可跳过（但台词较慢，鼓励玩家"听"完） | — |

#### 7.2.4 urgent（紧急介入）

| 属性 | 规格 | 来源 |
|------|------|------|
| 触发条件 | 所有 HARM_GUIDE；或 NIHILISM 达到临界值 | 存在保护 GDD §2.2.1 |
| 天使表情 | `resolute`（坚定，不是恐慌） | — |
| 天使移动 | **瞬间出现在心爱的身前**（无移动动画） | — |
| 拥抱动画 | 紧紧拥抱（2秒） | — |
| 台词呈现 | **慢速逐字**（每字 0.1 秒间隔，比正常慢 3 倍） | 存在保护 GDD §2.1.9 |
| 翅膀变化 | 大幅暗淡 | — |
| 跳过 | **禁用跳过**（`disable_skip()`） | 存在保护 GDD §2.1.9 |
| 恢复后 | **10 秒安息场景**（天使安静陪伴，无台词） | Phase2 视觉对齐 §4.6 |

### 7.7 可访问性降级映射

当玩家开启可访问性设置时，暗流 UX 的降级行为：
