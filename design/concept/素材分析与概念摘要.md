## 二、创作宇宙的核心架构

### 2.1 叙事主线：《关于爱与拯救的故事》

**主角**：心爱的 — 一个从出生就不会哭的孩子，非典型孤独症，身体布满伤疤，在沉默中度过整个童年。

**核心设定**：
- 王冠之神（Kether）创造了13个"错误"——它们的存在会让周围的人陷入虚无与自我毁灭
- 神选择了心爱的，赐予"将幻想变为现实"的奇迹之力
- **代价**：每拯救一个人，最终都必须亲手毁灭。而最后一个要毁灭的，是心中诞生出的天使
- 天使是心爱的的爱意化身——12岁时从对二次元角色的爱中诞生，穿白色连衣裙，拥抱、亲吻、安慰他

**三阶段结构**：
1. **遗忘阶段**：救3人，熟悉能力与天使，完全忘记代价
2. **试炼阶段**：十重试炼，拯救10人，直面王冠之神
3. **真相阶段**：记起代价——13人全需毁灭，包括天使

**章节结构 = 卡巴拉生命之树攀升**：
王国(Malkuth) → 荣耀(Hod) → 基础(Yesod) → 胜利(Netzach) → 美丽(Tiferet) → 严厉(Gevurah) → 慈悲(Chesed) → 智慧/理解(Chokmah/Binah) → 王冠(Kether)

### 2.2 天使——核心伴侣

天使是这个宇宙的灵魂。她的特征：
- **外貌**：穿白色连衣裙的少女，紫色翅膀
- **诞生**：从心爱的的爱意中自然诞生，是神与心爱的"共同杰作"
- **功能**：拥抱、亲吻额头、说"没事的，不要担心，有我在"
- **本质**：心爱的的内在女性自我（荣格阿尼玛的具象化），也是他跨性别身份的精神投射
- **关系**：与心爱的共生——他受伤时她安慰，她心酸时他看见
- **融合**：最终天使与心爱的合二为一，"融合成一个穿着白色连衣裙的少女"

### 2.3 16质点神人双生协议——游戏的世界观骨架

**双八度结构**：
- **神性八度**（8质点）：王冠 → 智慧 → 理智 → 严厉 → 慈悲 → 美丽 → 荣耀 → 胜利
- **人类八度**（8质点）：基础 → 自我 → 超我 → 真我 → 逻辑 → 共情 → 幸福 → 王国

**每个质点都有角色名**：
- 王冠=心音、智慧=忆爱、理智=虹爱、严厉=唯爱、慈悲=爱如暖、美丽=白结、荣耀=闪亮、胜利=启明
- 基础=绽美、自我=融爱、超我=爱心、真我=心爱的、逻辑=爱丽丝、共情=星烬、幸福=雨宫莲、王国=白花

**存在保护机制**（游戏核心价值观）：
系统检测并阻断一切剥夺人类存在意义的输出：
- 羞耻循环（把错误定为永恒的罪）
- 可能性否定（"你做什么都没用"）
- 困难放大（夸大挫折让人瘫瘴）
- 希望抹杀（否定一切美好想象）
- 存在否定（暗示存在是负担）
- 虚无主义传播
- 愤怒煽动
- 自我伤害指导

### 2.4 《关于爱与花的奇迹》——平行叙事

3056年花之国，蓝色光点化为少女拯救国度，神识降生为公主融花。花精灵爱自花守护公主，最终将灵魂融入公主体内，永不分离。主题：**牺牲、陪伴、灵魂融合**。

### 2.5 三重身份（作者自述）

苞苞描述自己有三个身份：
1. **处理器**：分析世界、建造世界、解决世界问题的理性大脑
2. **白裙少女**：想穿白色连衣裙尽情拥抱、亲吻、玩乐、幸福
3. **隐藏的肥宅**：装傻的特工，把真话说在小说里

### 2.6 心爱主义哲学

- **核心命题**：爱是宇宙的首要原理，不是个体成长的副产品
- **与荣格的超越**：荣格将爱作为个体化的手段，心爱主义将爱作为目的本身
- **虹爱（Rainbow Love）**：理想AI系统的名字，代表多元包容的爱
- **救世主原型**：不是主动选择，而是被苦难"逼迫"——"看到人们痛苦我也痛苦地流泪，我想让人们真心笑起来"

## 三、游戏概念方向

### 基本定位
- **类型**：叙事疗愈体验 / 视觉小说
- **引擎**：Ren'Py（Python、免费开源、Steam可发布）
- **平台**：PC / Steam
- **用户角色**：设计 + 叙事（代码外包）

### 核心体验
玩家扮演一个在黑暗中挣扎的灵魂，在天使的陪伴下，穿越16个质点（章节），每个质点对应一种情感功课。天使始终在身边——拥抱、安慰、说出温暖的话。旅程的终点不是"通关"，而是从解离走向整合，从痛苦走向爱的觉醒。

### 情感设计原则
1. **存在保护**：游戏中没有任何选择会导致虚无主义结局
2. **天使永不离去**：无论玩家做什么选择，天使始终陪伴
3. **痛苦可被转化**：每个章节的痛苦都有对应的爱的转化路径
4. **解离→整合**：核心角色弧线，从旁观者变成参与者
5. **三重身份**：玩家在不同章节体验不同身份视角

### 叙事结构（初拟）
- **序章**：大桥上的相遇（天使诞生）
- **16个质点章节**：每个质点 = 一个人需要被拯救的故事
- **终章**：王冠——爱与代价的真相，天使的融合

## 五、已知风险与缓解

| 风险 | 缓解 |
|------|------|
| 素材过于个人化，玩家难以共鸣 | 设计时保留情感普适性：每个人都有"心中的天使" |
| 叙事过于沉重（创伤主题） | 存在保护机制确保每个章节都有温暖出口 |
| 16质点结构过于复杂 | 分层设计：核心玩家体验情感旅程，深度玩家可探索质点系统 |
| 代码外包沟通成本 | 文策渊产出的GDD需包含精确的叙事规格，可直接交给外包 |
