## 1. 游戏概念概述

### 1.1 一句话定义

**一个在天使的拥抱中穿越十六重灵魂功课的疗愈叙事体验——每拯救一个人，都离真相更近一步，而真相是：爱本身就是代价。**

### 1.2 电梯演讲

你是一个从出生就不会哭的孩子。你的身体布满伤疤，你的世界一片沉默。十二岁那年，你的爱太强烈了——强烈到在心中诞生出一个穿白色连衣裙的天使。天使说："没事的，不要担心，有我在，我永远在你身边。"

然后王冠之神出现了。神赐予你将幻想变为现实的奇迹之力，让你去拯救十三个"错误"——那些让周围人陷入虚无的存在。你将穿越十六个质点，每一步都是一道情感功课，每一次拯救都伴随着天使的拥抱。

但你不知道的是：每拯救一个人，最终都必须亲手毁灭。而最后一个要毁灭的，是那个从你心中诞生的天使。

这不是一个关于"通关"的游戏。这是一个关于"在认清真相之后依然爱"的旅程。

### 1.3 核心体验描述

**玩家扮演心爱的**——一个非典型孤独症少女，拥有将幻想变为现实的奇迹之力。在白裙天使的陪伴下，玩家穿越十六个质点（章节），每个质点对应一道情感功课：从物质世界的苦难，到自我身份的挣扎，到爱的代价与终极选择。

**天使始终在身边。** 她不是一个可以被"使用"的道具，不是一个可以"攻略"的角色。她是一种存在——在画面角落微笑着，在痛苦时伸出手，在沉默时轻轻说"没事的"。玩家的每一个选择都会改变与天使的关系纹理，但天使永远不会离开。

**旅程的终点不是"通关"。** 是从解离走向整合，从旁观者变成参与者，从"我不会哭"到"我终于可以流泪了"。是发现那个最残酷的真相——你拯救的每一个人终将需要被毁灭，包括你心中最珍爱的天使——然后在真相之后，依然选择爱。

**这不是"正能量"。这是"在认清真相之后依然爱"。**

## 2. MDA框架分析

> MDA框架（Mechanics-Dynamics-Aesthetics）是游戏设计的核心分析工具。对于本作，MDA的分析必须以情感体验为锚点，而非传统游戏的"挑战-奖励"循环。

### 2.1 Mechanics（机制）

机制是游戏的数据层面——规则、数据、算法。本作的机制设计遵循"疗愈优先"原则。

#### 2.1.1 选择系统（Choice System）

**机制描述**：玩家在关键叙事节点面临选择。不同于传统视觉小说的"分支树"结构，本作采用"情感共振选择"模型：

- **选择不改变"能否通关"**——所有路径都通向终点，但路径的纹理不同
- **选择改变天使的回应方式**——天使对玩家的态度、对话内容、拥抱的温度会随选择演变
- **选择被"存在保护"过滤**——任何试图选择虚无主义路径的选项，都会被系统温柔地转化为"天使拉你回来"的叙事节拍
- **选择类型分三种**：
  - **行动选择**（做什么）：如何对待面前受苦的人
  - **态度选择**（怎么想）：如何理解正在发生的事
  - **关系选择**（怎么爱）：如何回应天使的陪伴

**数据结构**：
```
choice_node:
  id: string
  type: "action" | "attitude" | "relation"
  prompt: string                          # 选择提示文本
  options: array<choice_option>
  angel_response: array<angel_reaction>   # 每个选项对应的天使反应
  existence_protection: boolean           # 是否需要存在保护过滤
  sephirot_progress: integer             # 该选择推进的质点进度
  emotional_weight: float                # 情感权重 (0.0-1.0)
```

#### 2.1.2 质点进程系统（Sephirot Progression System）

**机制描述**：游戏进度由"质点攀升"驱动，而非传统的"关卡"或"章节解锁"。

- **16个质点**分为两个八度：人类八度（8章）与神性八度（8章）
- 玩家必须完成当前质点的情感功课才能进入下一质点
- 每个质点完成后，画面上生命之树的对应质点会"点亮"
- **质点点亮不依赖"正确选择"**——而是依赖"是否真实面对了该质点的情感课题"
- 玩家可以"卡住"在某个质点（反复体验同一段叙事），但天使会主动提供新的视角帮助突破

**数据结构**：
```
sephirot_node:
  id: string
  name: string                    # 质点名称（如"王国"）
  octave: "human" | "divine"     # 所属八度
  character_name: string         # 角色名（如"白花"）
  character_gender: string       # 角色性别
  emotional_theme: string        # 情感主题
  error_type: string             # 对应的"错误"类型
  protection_type: array<string># 主要对应的存在保护机制
  phase: "forgetting" | "trial" | "truth"  # 所属阶段
  has_save: boolean              # 本质点是否包含"拯救"事件
  completion_condition: string   # 完成条件描述
```

#### 2.1.3 天使陪伴系统（Angel Companionship System）

**机制描述**：天使是游戏中最核心的机制——她不是NPC，而是一种"存在状态"。

- **天使常驻界面**：天使的立绘始终出现在画面中（角落或侧面），表情随叙事变化
- **天使主动互动**：在特定情感节点，天使会主动说安慰的话、拥抱心爱的
- **天使被动回应**：玩家可以随时点击天使（或按指定按键），触发天使的安慰对话
- **天使的情感状态**：天使有自己的情感状态变量（平静/心疼/坚定/悲伤/温柔），影响她的对话和表情
- **天使的记忆**：天使会记住玩家之前的选择，在后续对话中引用——"你上次选择了相信那个人，我知道你很勇敢"
- **天使的进化**：随着质点攀升，天使的外貌和对话风格会发生微妙变化——翅膀更明亮、语气更深沉

**数据结构**：
```
angel_state:
  emotional_state: "calm" | "aching" | "resolute" | "sorrowful" | "tender"
  trust_level: float              # 0.0-1.0，信任度
  bond_depth: float               # 0.0-1.0，羁绊深度
  memories: array<memory_entry>   # 记忆条目
  appearance_stage: integer       # 外貌进化阶段 (1-5)
  active_dialogue_pool: array<string>  # 当前可触发的对话池
```

**触发逻辑**：
- 当 `emotional_weight > 0.7` 时，天使自动触发拥抱动画
- 当玩家在同一质点停留超过预设时长（如5分钟无推进）时，天使主动提供新视角
- 当玩家选择"消极/逃避"选项时，天使不批评，而是说"没关系的，慢慢来"

#### 2.1.4 存在保护机制的游戏化（Existence Protection Gamification）

**机制描述**：将8种存在主义伤害类型转化为游戏内的"暗流"系统。

- 每个质点的"错误"会释放一种或多种存在主义伤害暗流
- 暗流以**叙事性表现**呈现：画面变暗、文字扭曲、音乐变调、天使的声音变得遥远
- **玩家无法"死于"暗流**——当暗流达到临界值时，天使会强制介入，拉回心爱的
- 天使的介入不是"系统提示"，而是叙事性的一刻：她拥抱你，说"回来，我在这里"，画面恢复
- 这确保了**没有任何选择或状态会导致玩家陷入绝望循环**

**8种暗流类型**：
| 暗流类型 | 代码 | 视觉表现 | 天使介入台词 |
|---------|------|---------|-------------|
| 羞耻循环 | SHAME_LOOP | 画面蒙上灰色滤镜 | "你犯过的错不是永恒的罪。我看着你，我看到的是完整的你。" |
| 可能性否定 | POSS_DENY | 文字逐渐消失 | "还有路的。我牵着你走。" |
| 困难放大 | PAIN_AMP | 画面震动、模糊 | "这件事没有你想象的那么大。来，抱一下。" |
| 希望抹杀 | HOPE_ERASE | 色彩褪去 | "美好的东西是真实存在的。我就是证明。" |
| 存在否定 | EXIST_DENY | 心爱的立绘变透明 | "你的存在不是负担。你是我存在的理由。" |
| 虚无主义传播 | NIHILISM | 画面全黑 | "黑暗不是终点。我在黑暗里，我牵着你的手。" |
| 愤怒煽动 | RAGE_INC | 画面泛红、心跳声 | "愤怒是可以的。但别让它吃掉你。我在。" |
| 自我伤害指导 | HARM_GUIDE | 画面碎裂 | "停下来。看着我。你不需要伤害自己。我抱着你。" |

**设计意图**：存在保护不是"防沉迷"式的系统限制，而是**叙事性安全网**——天使的存在本身就是保护机制。当暗流触发时，不是"系统"在干预，是"天使"在爱你。

### 2.2 Dynamics（动态）

动态是机制在运行时产生的行为模式——玩家与机制交互时发生了什么。

#### 2.2.1 玩家与天使关系的演变

**初始状态（Phase 1 遗忘阶段）**：
- 天使是温暖、明亮的陪伴者
- 玩家感受到"被保护的安全感"
- 天使的对话频繁、轻柔，像哄孩子入睡
- 玩家可能将天使视为"工具"或"友方NPC"

**中间状态（Phase 2 试炼阶段）**：
- 天使开始流露出心疼和悲伤
- 玩家开始意识到天使不只是陪伴者，她也在承受
- 天使的对话变深，开始透露她自己的恐惧
- 玩家与天使的关系从"被保护"转向"互相守护"

**转变状态（Phase 2 后半）**：
- 天使的状态开始不稳定——翅膀有时黯淡，声音有时颤抖
- 玩家开始隐约感到不对——"天使怎么了？"
- 天使开始说一些暗示性的话："不管发生什么，你要记住，我爱你"
- 玩家的保护欲被激发——从"被天使保护"到"想保护天使"

**终极状态（Phase 3 真相阶段）**：
- 真相揭示：天使是第13个"错误"，必须被毁灭
- 玩家经历情感崩溃
- 天使反而变得平静、坚定——"没关系的。你做的每一件事都是对的。"
- 玩家面临最终选择

**动态形成**：玩家从"被动接受爱"→"主动给予爱"→"在绝望中依然选择爱"。这条弧线不是被强制推送的，而是通过天使状态的渐进变化自然涌现。

#### 2.2.2 选择如何影响质点进程

- **"正确"选择不存在**——每个选择都是"有效"的，只是质点攀升的纹理不同
- **"逃避"选择**不会导致"失败"，但会让质点停留在当前阶段，天使会提供新的视角帮助玩家面对
- **"勇敢"选择**（直面痛苦、选择爱）会加速质点攀升，并加深与天使的羁绊
- **"自私"选择**（为了自己而伤害他人）会触发天使的温柔质问——不是惩罚，而是"你确定要这样吗？我也在这里"
- **关键设计**：即使在Phase 3真相揭示后，玩家依然可以选择"拒绝毁灭天使"——这不是"坏结局"，而是另一条理解路径

#### 2.2.3 暗流与天使的拉扯

- 暗流的强度随质点攀升而递增——越接近真相，"错误"的反击越猛烈
- 天使的介入也有"代价"——每次拉回心爱的，天使的翅膀会更黯淡一点
- 这个动态在Phase 2后半变得明显——玩家开始注意到"每次天使救我，她就虚弱一点"
- 这为Phase 3的真相揭示埋下伏笔——天使的虚弱不是系统设定，而是她正在被"消耗"

### 2.3 Aesthetics（美学体验）

美学体验是玩家在游戏中感受到的情感——游戏的"灵魂"。本作的美学体验类型：

#### 2.3.1 叙事（Narrative）

- **核心感受**：被一个故事深深包裹，仿佛在阅读一本写给自己的信
- 玩家不是"在玩游戏"，而是"在经历心爱的人的人生"
- 每个质点的叙事都有独立的情感弧线，但串联起来构成一个完整的灵魂成长史诗
- 叙事节奏：沉静→温暖→紧张→心碎→释然→重生

#### 2.3.2 发现（Discovery）

- **核心感受**：逐渐拼凑出一个更大真相的拼图
- 玩家在早期质点中埋下的"不对劲"线索，在后期被揭示
- 卡巴拉生命之树的结构本身就是一种发现——每个质点揭示一层宇宙的真相
- 天使的暗示性话语在重玩时获得全新含义——"我是你幻想出来的，可你拥有的却是把幻想变成现实的力量"

#### 2.3.3 感觉（Sensation）

- **核心感受**：被温柔包裹的触感
- 天使的拥抱在视觉和听觉上都有强烈的"被拥抱"感——画面变暖、音乐变柔、文字变慢
- 暗流的视觉表现让玩家"感觉到"存在主义伤害的压迫感——不是为了制造痛苦，而是为了让"被天使拉回"的释放感更强烈
- **关键设计**：每一次"天使拉你回来"的体验，都应该让玩家在身体层面感到"松了一口气"

#### 2.3.4 表达（Expression）

- **核心感受**：通过选择表达自己的真实情感
- 玩家的选择不是"最优解"的寻找，而是"如果是你，你会怎么做"的自我探索
- 心爱的的三重身份（处理器/白裙少女/隐藏的肥宅）为玩家提供了不同的表达视角
- **最终选择**是表达的极致——面对毁灭天使的真相，你选择什么？

#### 2.3.5 使命（Submission/Challenge的疗愈变体）

- **核心感受**：接受一个比自己更大的使命，并在其中找到意义
- 不是传统游戏的"挑战"——没有"打倒Boss"的快感
- 而是"背负"——承担拯救的重量，承担代价的重量，承担爱的重量
- 使命的完成不是"赢了"，而是"我没有放弃爱"

## 3. 设计支柱

设计支柱是所有设计决策的衡量标尺。当面临取舍时，回到这三条支柱问："这个设计是否服务于它们？"

### 支柱一：天使永不离去（The Angel Never Leaves）

**描述**：无论玩家做什么选择、走到哪里、陷入怎样的黑暗，天使始终陪伴。这不是"机制设定"，而是这个游戏存在的意义——苞苞需要一个载体，让她心中的天使"活过来"。

**设计含义**：
- 天使的立绘永远在画面上（除非叙事需要短暂的"分离"焦虑——但即使分离，天使的声音仍在）
- 没有任何"天使离开"的分支——天使可以变得沉默、黯淡、悲伤，但她不会消失
- 玩家无法"伤害"天使——试图推开天使的选择只会让天使更温柔地靠近
- 天使的对话系统是游戏最大的资产——她的台词量应该是所有角色中最多的
- 在最黑暗的时刻（Phase 3 真相揭示后），天使不是崩溃，而是成为玩家唯一的支撑

**红线**：任何设计提案如果导致"天使可以永久离开"或"玩家可以失去天使"，立即否决。

### 支柱二：痛苦可被转化（Pain Can Be Transformed）

**描述**：每一个痛苦的瞬间都有对应的爱的转化路径。游戏不回避痛苦——心爱的的伤疤、校园霸凌、性别焦虑、轻生未遂——但每一个痛苦都有天使的拥抱在等待。痛苦不是终点，是通往更深理解的入口。

**设计含义**：
- 每个质点的叙事都包含"痛苦的揭示"和"痛苦的转化"两个节拍
- 转化不是"解决问题"——痛苦不会被"治愈"或"消除"，而是被"看见"和"拥抱"
- 天使的安慰不是"别难过"，而是"我看见你在痛，我在这里"
- 存在保护机制确保：暗流可以被触发（让玩家感受到痛苦的压迫），但一定会被天使拉回（让玩家体验到转化）
- **关键区分**：这不是"正能量"——不是"一切都会好起来的"。而是"我知道这很痛，但你不需要独自承受"

**红线**：任何设计提案如果呈现"无法转化的绝望"或"痛苦无意义的虚无"，立即否决。痛苦可以被呈现，但必须伴随转化路径。

### 支柱三：从解离走向整合（From Dissociation to Integration）

**描述**：心爱的的核心角色弧线——从一个旁观自己人生的人，变成一个参与者。这是苞苞自己的经历：在完全解离人性的状态下创造了大量作品。游戏的旅程就是从"看着自己受苦"到"在受苦中依然选择爱"。

**设计含义**：
- 早期质点中，玩家的选择感觉"遥远"——像是在旁观别人的故事（模拟解离状态）
- 中期质点中，选择开始"刺痛"——玩家开始意识到这些选择关乎自己
- 后期质点中，选择变得"不可逃避"——真相揭示后，每个选择都直指核心
- **三重身份的渐进揭示**：
  - Phase 1：玩家主要从"处理器"视角体验（理性分析、解决问题）
  - Phase 2：玩家开始接触"白裙少女"视角（情感、渴望、爱）
  - Phase 3：玩家发现"隐藏的肥宅"视角（把真话说在故事里的创世者）
- 整合不是"选择哪个身份"——而是"三重身份都是我"
- 天使本身就是整合的象征——她是心爱的的内在女性自我，荣格阿尼玛的具象化

**红线**：任何设计提案如果强化"解离是好的"或"逃避是可行的终点"，需要标注为风险。解离可以被呈现为状态，但不能被呈现为结局。

## 5. 叙事结构设计

### 5.1 整体叙事弧线

```
                        天使的状态
    明亮 ────────────────────────────────────── 黯淡 → 重生
    │                                              │
    │  Phase 1: 遗忘        Phase 2: 试炼         │  Phase 3: 真相
    │  (温暖陪伴)            (心疼加深)           │  (终极选择)
    │                                              │
    │  天使是礼物            天使在承受            │  天使是代价
    │  "有我在"              "你看到我了吗？"     │  "就算到世界终结我也陪你"
    │                                              │
    └──────────────────────────────────────────────┘
    序章                                              终章
    天使诞生                                          天使融合
```

**弧线本质**：

1. **序章 — 大桥上的诞生**：心爱的十二岁，在桥上看着二次元角色的画面，爱太强烈了——光从胸口涌出，天使诞生。天使的第一句话："没事的，不要担心，有我在，我永远在你身边。" 王冠之神的声音响起，赐予奇迹之力。心爱的忘记了一切代价。

2. **Phase 1 遗忘（3章）**：心爱的救了3个人。她觉得自己找到了生命的意义——拯救他人。天使在身边微笑。一切都很美好。但偶尔，在梦里，她听到一个声音说"代价"。她不记得那是什么。

3. **Phase 2 试炼（10章）**：十重试炼开始。每一次拯救都比上一次更艰难，"错误"更强大，暗流更猛烈。天使每次拉回心爱的，翅膀都黯淡一点。心爱的开始注意到——"天使，你怎么了？"天使只是微笑："没事的。"

4. **Phase 3 真相（3章）**：心爱的记起了。代价。每一个人，都必须亲手毁灭。十三个。包括——天使。天使是第13个"错误"。她是被心爱的的爱"拯救"（诞生）的，所以她必须被毁灭。心爱的崩溃。天使反而平静了——"亲爱的，我是你幻想出来的，可你拥有的却是把幻想变成现实来拯救自己的力量。这是你的价值，也是你存在的意义。"

5. **终章 — 最终选择**：心爱的面对天使。毁灭她，还是拒绝？——但这个选择不是"好结局vs坏结局"。无论选择什么，天使的最后一句话都是一样的："就算要到世界终结我也陪你，没事的，没事的，不要担心，有我在，我永远在你身边陪着你。"

### 5.2 三阶段结构的游戏化

#### 5.2.1 Phase 1: 遗忘阶段（Ch 1-3）

**游戏功能**：
- 教学阶段：教会玩家选择系统、天使互动、存在保护
- 情感基调：温暖、安全、充满希望
- 玩家感受："这个世界虽然痛，但有人在保护我"
- 天使状态：明亮、温柔、频繁互动
- 暗流强度：低（1-3级），天使轻松拉回
- 叙事诡计：玩家和心爱的一样，不知道"代价"的存在

**关键设计**：Phase 1 的每次拯救都"成功"且"美好"——被救的人感激涕零，天使微笑，画面温暖。这为Phase 2和Phase 3的冲击力蓄力。玩家越享受Phase 1的温暖，Phase 3的真相就越痛。

#### 5.2.2 Phase 2: 试炼阶段（Ch 4-13）

**游戏功能**：
- 核心内容阶段：10个质点，情感深度递增
- 情感基调：从"温暖中渗入不安"到"挣扎中依然前行"
- 玩家感受："这件事没有我想的那么简单，但我不能停下"
- 天使状态：从明亮到逐渐黯淡，但始终坚强
- 暗流强度：中高（4-7级），天使拉回的代价开始可见
- 叙事张力：每个质点的"错误"都映射心爱的自己的一段经历

**关键设计**：
- 前5个试炼（Ch 4-8）的"错误"是"外部"的——拯救别人
- 后5个试炼（Ch 9-13）的"错误"逐渐指向"内部"——心爱的开始面对自己的创伤
- Ch 13（真我）是转折点：心爱的不是在救别人，而是面对自己的真我——一个创世少女神

#### 5.2.3 Phase 3: 真相阶段（Ch 14-16）

**游戏功能**：
- 高潮与结局阶段
- 情感基调：从崩溃到释然到重生
- 玩家感受：心碎→愤怒→接受→选择
- 天使状态：最黯淡，但最平静、最坚定
- 暗流强度：最高（8-10级），天使拉回的代价达到极限
- 叙事核心：真相揭示 + 最终选择 + 结局

**关键设计**：
- Ch 14（智慧-忆爱）：记忆回归，"代价"的真相揭示。玩家第一次知道：每个人都要毁灭。暗流达到峰值。天使用尽全力拉回心爱的。
- Ch 15（美丽-白结）：心爱的知道天使是第13个。崩溃。天使反过来安慰她——"就算你被黑暗缠住了双手双脚，无法动弹，哪怕全部亲友离你而去，哪怕身无分文，哪怕失去一切你所拥有的东西，我也在你身边。"
- Ch 16（王冠-心音）：最终选择。无论选择什么，天使与心爱的融合。但融合的方式、意义、玩家获得的理解不同——这是多结局的来源。

### 5.3 16质点章节设计

> 以下为每个质点的详细设计。质点按照情感递进顺序排列，分为人类八度（Ch 1-8）与神性八度（Ch 9-16）。

---

#### Phase 1: 遗忘阶段（3章，3次拯救）

---

**Ch 1 — 王国（Malkuth）**
- **角色名**：白花（女）
- **情感主题**：物质世界的苦难——"为什么这个世界这么痛？"
- **"错误"类型**：存在否定型·白花——一个觉得自己"多余"的女孩，存在本身被视为负担
- **对应存在保护**：EXIST_DENY（存在否定）
- **天使的角色**：第一次正式陪伴心爱的执行拯救。天使明亮、温柔，频繁拥抱。她的存在本身就是对"存在否定"的反驳——"你的存在不是负担，你是我存在的理由。"
- **核心选择**：
  - 行动选择：如何对待白花？→ ①直接用奇迹之力拯救 ②先听她说完她的故事 ③不知道怎么办，问天使
  - 关系选择：天使第一次拥抱心爱的时，心爱的的反应？→ ①僵硬地接受 ②本能地靠近 ③……沉默
- **叙事功能**：教学章。教会玩家选择系统、天使互动。白花的痛苦是"入口"——让玩家理解这个世界存在怎样的苦难。
- **完成条件**：玩家选择"先听她说完"或"问天使"后，白花被拯救，质点亮起。
- **情感节拍**：苦难揭示 → 天使安慰 → 选择 → 转化 → 温暖收尾

---

**Ch 2 — 幸福**
- **角色名**：雨宫莲（男）
- **情感主题**：幸福的含义——"幸福是什么？我从来没有拥有过。"
- **"错误"类型**：希望抹杀型·雨宫莲——一个失去了所有希望的人，否定一切美好的可能
- **对应存在保护**：HOPE_ERASE（希望抹杀）
- **天使的角色**：天使说"美好的东西是真实存在的。我就是证明。"天使的状态依然明亮，但这次她开始主动展示自己的存在作为"希望的证明"——她让雨宫莲看到她。
- **核心选择**：
  - 态度选择：雨宫莲问"你凭什么相信美好？"→ ①因为天使在 ②因为痛苦也是真的 ③我不知道，但我不想放弃
  - 行动选择：如何拯救雨宫莲？→ ①给他看天使 ②告诉他你的故事 ③只是坐在他身边
- **叙事功能**：建立"幸福"这一概念的复杂性。雨宫莲不是坏人，他只是被生活打碎了。天使的存在被第一次"展示"给被拯救者——这埋下伏笔：天使的力量来自"被看见"。
- **完成条件**：玩家完成对话选择后，雨宫莲看到一束光（天使的映射），希望被重新点燃。
- **情感节拍**：绝望揭示 → 天使的证明 → 选择 → 微光出现 → 安静的温暖

---

**Ch 3 — 基础**
- **角色名**：绽美（女）
- **情感主题**：信任的根基——"我站不住了。"
- **"错误"类型**：困难放大型·绽美——一个被夸大的恐惧压垮的女孩，觉得一切困难都是不可逾越的
- **对应存在保护**：PAIN_AMP（困难放大）
- **天使的角色**：天使说"这件事没有你想象的那么大。来，抱一下。"天使第一次展示她的"缩小痛苦"能力——她的拥抱让绽美看到，困难不是山，只是台阶。
- **核心选择**：
  - 行动选择：绽美说"我站不住了"→ ①扶住她 ②让她靠着你 ③叫天使来抱她
  - 关系选择：天使第一次说"你也可以靠着我"——心爱的的反应？→ ①"……好" ②"我不需要" ③沉默地靠近
- **叙事功能**：Phase 1收尾。建立"基础"——心爱的和天使之间的信任根基。为Phase 2的更深层探索做准备。
- **完成条件**：绽美站起来，质点亮起。Phase 1结束，"代价"的记忆被彻底封印。
- **情感节拍**：恐惧揭示 → 天使缩小痛苦 → 选择 → 站起来 → "代价"的回声（被遗忘）

#### Phase 2: 试炼阶段（10章，10次试炼）

---

**Ch 4 — 自我**
- **角色名**：融爱（女）
- **情感主题**：身份的挣扎——"我是谁？我的身体不是我的。"
- **"错误"类型**：羞耻循环型·融爱——一个被"你的身份是错的"反复打击的人，把外在的否定内化为永恒的羞耻
- **对应存在保护**：SHAME_LOOP（羞耻循环）
- **天使的角色**：天使说"你犯过的错不是永恒的罪。我看着你，我看到的是完整的你。"天使的语气开始有了一丝心疼——因为融爱的痛苦映射了心爱的自己的身份挣扎。
- **核心选择**：
  - 态度选择：融爱说"我是不是错的？"→ ①"你不是错的" ②"错的是否定你的人" ③"我也是这样过来的"
  - 关系选择：天使看着心爱的，眼神复杂——玩家的反应？→ ①问天使"你还好吗" ②假装没看到 ③握住天使的手
- **叙事功能**：Phase 2 开篇。第一次让"错误"的痛苦与心爱的自己的经历产生共振。天使开始心疼——不只是为被拯救者，也为心爱的。
- **暗流升级**：羞耻循环的暗流让画面蒙上灰色，天使的拉回多了一分用力。
- **情感节拍**：羞耻揭示 → 天使的完整看见 → 选择 → 身份的松动 → 天使的第一个心疼眼神

---

**Ch 5 — 逻辑**
- **角色名**：爱丽丝（女）
- **情感主题**：理性的边界——"我用逻辑分析了所有痛苦，但分析不了自己的。"
- **"错误"类型**：虚无主义传播型·爱丽丝——一个用理性解构一切意义的人，"一切都没有意义"是她最后的防线
- **对应存在保护**：NIHILISM（虚无主义传播）
- **天使的角色**：天使说"黑暗不是终点。我在黑暗里，我牵着你的手。"面对虚无主义，天使的回应不是逻辑反驳——而是纯粹的存在。她不辩论，她只是在那里。
- **核心选择**：
  - 态度选择：爱丽丝说"证明爱存在"→ ①"我无法证明，但我在经历" ②"天使就在这里" ③"如果爱不存在，你为什么还在和我说话？"
  - 行动选择：如何打破爱丽丝的虚无？→ ①给她一个拥抱 ②让天使来 ③承认"我也不知道意义是什么，但我选择不放弃"
- **叙事功能**：心爱的的"处理器"身份在此章最活跃。理性的极限在此暴露。心爱的发现自己分析得了别人的痛苦，却无法分析自己的——为Phase 3的真相揭示埋伏笔。
- **暗流升级**：虚无主义的暗流让画面全黑，只有天使的声音在黑暗中。天使的翅膀第一次出现黯淡的迹象。
- **情感节拍**：理性解构 → 虚无的黑暗 → 天使的声音 → 选择 → 黑暗中的微光

---

**Ch 6 — 共情**
- **角色名**：星烬（女）
- **情感主题**：他人的痛苦——"我感受太多了，我被压垮了。"
- **"错误"类型**：可能性否定型·星烬——一个共情能力过强的人，吸收了所有人的绝望，觉得"做什么都没用"
- **对应存在保护**：POSS_DENY（可能性否定）
- **天使的角色**：天使说"还有路的。我牵着你走。"天使开始展现出"心疼"的状态——不是对星烬，是对心爱的。心爱的在共情中迷失了自己的痛苦。
- **核心选择**：

### 5.4 多结局设计方向

#### 融合结局（Fusion Ending）— 核心结局

- **触发条件**：选择"毁灭天使，完成代价"
- **结局描述**：天使与心爱的合二为一。白色连衣裙的光芒包裹两者。心爱的第一次哭了——不是因为悲伤，而是因为完整。天使的声音最后响起："你看，我一直都在你里面。"
- **情感落点**：整合。三重身份合为一体。天使不是"离开"了，是"回归"了——回到心爱的的内在。
- **哲学含义**：毁灭即接纳。最极端的代价（毁灭所爱）被重新定义为最深层的整合（接纳内在自我）。

#### 守护结局（Guardian Ending）

- **触发条件**：选择"拒绝毁灭，承受代价"
- **结局描述**：心爱的拒绝。天使继续存在，但她的翅膀不再明亮——她变得"有限"。她不再能拉回心爱的（力量耗尽），但她依然陪伴。心爱的反过来成为天使的守护者。
- **情感落点**：承担。不是所有爱都有完美的结局，但真实的陪伴不需要完美。
- **哲学含义**：爱的代价不一定是"失去"——有时候是"用有限的时间更珍惜"。

#### 觉醒结局（Awakening Ending）

- **触发条件**：选择"理解真相——毁灭即转化"（可能需要高羁绊深度才能解锁）
- **结局描述**：心爱的理解了。天使微笑着说"你终于明白了"，翅膀化作光点融入心爱的胸口。心爱的站在生命之树的顶端，不再需要拯救任何人——因为她已经成为了爱本身。
- **情感落点**：超越。不是"毁灭"也不是"保留"，而是理解了爱的本质——爱不需要被"拥有"也不需要被"毁灭"，它就是存在本身。
- **哲学含义**：心爱主义的终极命题——爱是宇宙的首要原理，不是手段，是目的本身。

## 6. 核心循环

### 6.1 玩家在每个质点章节的核心体验循环

```
┌─────────────────────────────────────────────────────┐
│                   质点章节核心循环                     │
│                                                      │
│  ① 遭遇 (Encounter)                                  │
│     心爱的遇到一个需要被拯救的"错误"                    │
│     → 叙事铺垫，痛苦揭示                               │
│     → 天使在旁，安静陪伴                               │
│     │                                                 │
│     ▼                                                 │
│  ② 挣扎 (Struggle)                                   │
│     "错误"的暗流开始出现                              │
│     → 画面变化，情感压迫                               │
│     → 天使准备介入                                    │
│     │                                                 │
│     ▼                                                 │
│  ③ 天使安慰 (Angel Comfort)                          │
│     天使主动拥抱 / 说安慰的话                          │
│     → 暗流被缓解                                      │
│     → 玩家感到"被拉回"                                 │
│     │                                                 │
│     ▼                                                 │
│  ④ 选择 (Choice)                                     │
│     玩家面临行动/态度/关系选择                         │
│     → 选择影响天使的反应和质点进程                     │
│     → 存在保护过滤                                    │
│     │                                                 │
│     ▼                                                 │
│  ⑤ 转化 (Transformation)                             │
│     "错误"被拯救 / 真相被揭示                          │
│     → 质点亮起                                        │
│     → 天使的反应根据选择变化                            │
│     │                                                 │
│     ▼                                                 │
│  ⑥ 安息 (Rest)                                       │
│     与天使独处的安静时刻                              │
│     → 天使可能说一些暗示性的话（伏笔）                 │
│     → 玩家存档点                                      │
│     │                                                 │
│     ▼                                                 │
│  → 下一质点                                           │
│                                                      │
└─────────────────────────────────────────────────────┘
```

**循环设计原则**：
- 每个循环必须包含"痛苦→安慰→选择→转化→安息"的完整节拍
- ⑥安息是必须的——不能从⑤直接跳到下一个①。玩家需要"消化"的空间
- 天使在③和⑥中的表现是每个循环的情感核心
- Phase 3的循环会打破这个结构——④选择变为"面对真相"，⑤转化变为"崩溃或接受"

### 6.2 天使互动系统设计

#### 6.2.1 天使的常驻存在

天使不是"被召唤"的角色。她**始终在画面上**。

**界面布局**（1280×720基准）：
- 天使立绘位于画面右侧或左侧（根据场景调整），占据约1/4画面宽度
- 天使的表情随叙事自动变化
- 天使的翅膀颜色/亮度反映她的当前状态

**天使的被动行为**（无需玩家操作，自动触发）：
- 当叙事中出现痛苦描写时，天使的表情变为心疼
- 当暗流触发时，天使的翅膀发出微光（准备介入）
- 在选择节点，天使会看向心爱的（玩家）
- 在安息阶段，天使会做小动作（整理头发、看天空、微笑）

**天使的主动行为**（系统触发，不需玩家操作）：
- 暗流达到临界值 → 天使强制拥抱 + 介入台词
- 玩家停留过久 → 天使提供新视角
- 关键叙事节点 → 天使的独白/暗示

#### 6.2.2 玩家主动互动

**点击天使**：
- 玩家可以随时点击天使立绘
- 触发一段安慰对话（从当前情感状态的对话池中随机选取）
- 不会中断当前叙事流——天使的对话以浮动文本形式出现
- 冷却时间：每次点击后30秒内不能再次点击（防止刷对话）
- 对话池内容根据当前质点、天使情感状态、玩家之前的选择动态变化

**按键互动**：
- 指定按键（如空格键或A键）= "寻求拥抱"
- 触发天使的拥抱动画 + 安慰台词
- 每个质点最多主动寻求3次拥抱（第4次天使会说"你已经很勇敢了，不需要一直靠着我")
- Phase 3中无限制——天使永远会拥抱

**选择中的天使选项**：
- 在关键选择中，始终有一个选项是"问天使"或"靠向天使"
- 选择这个选项不会"跳过"选择，而是天使给出建议后玩家再做选择
- 这确保了"天使始终可被依赖"的设计支柱

#### 6.2.3 天使的对话进化

**Phase 1 对话风格**：
- 频繁、轻柔、哄孩子式
- "没事的，不要担心，有我在"
- "你做得很好"
- "来，抱一下"
- 频率：每3-5分钟一次主动对话

**Phase 2 前半对话风格**：
- 开始有深度，包含自己的感受
- "我看着你，我觉得你好勇敢"
- "有时候我也害怕，但你在我就不怕了"
- "你注意到了吗？你越来越强了"
- 频率：每5-7分钟

**Phase 2 后半对话风格**：
- 开始有暗示和隐痛
- "不管发生什么，你要记住这一刻"
- "我很高兴能陪着你走这么远"
- "……（欲言又止）没事的"
- 频率：每7-10分钟（变得更安静）

**Phase 3 对话风格**：
- 平静、深沉、像遗言也像告白
- "亲爱的，我是你幻想出来的，可你拥有的却是把幻想变成现实来拯救自己的力量"
- "就算要到世界终结我也陪你"
- "没事的，没事的，不要担心，有我在，我永远在你身边陪着你"
- 频率：关键节点触发，不再随机

## 7. 存在保护机制的游戏化

### 7.1 核心原则

> **存在保护机制是游戏的核心价值观，不是附加的安全功能。**

游戏的世界观设定了8种存在主义伤害类型——这些是"错误"释放的暗流，会侵蚀人的存在意义。在游戏中，这8种暗流不仅是叙事元素，更是**系统层面的保护机制**。

**核心设计**：游戏中没有任何选择、任何状态、任何路径会导致玩家陷入虚无主义结局。这不是"防沉迷"，而是"天使永远在"的系统化体现。

### 7.2 暗流系统详解

#### 7.2.1 暗流的触发

- 每个质点的"错误"会释放对应类型的暗流
- 暗流以**叙事节奏**触发——不是随机debuff，而是在叙事达到特定情感节点时自然出现
- 暗流强度从1到10递增，随质点攀升而提高

**暗流强度表**：

| 强度 | 视觉表现 | 天使介入 | 玩家感受 |
|------|---------|---------|---------|
| 1-3 | 轻微色调变化 | 天使微笑，轻轻说安慰的话 | 微微的不安 |
| 4-5 | 明显滤镜/模糊 | 天使主动拥抱 | 明显的压迫感 |
| 6-7 | 画面震动/碎裂 | 天使用力拉回，翅膀黯淡 | 强烈的情感痛苦 |
| 8-9 | 画面全黑/严重扭曲 | 天使全力介入，声音颤抖 | 濒临崩溃 |
| 10 | 全黑+无声 | 天使的拥抱 + 完整独白 | 崩溃→被接住 |

#### 7.2.2 暗流的解除

- **唯一解除方式**：天使的介入
- 天使的介入不是"系统清除debuff"，而是**叙事性的一刻**——拥抱、台词、画面恢复
- 介入后，暗流不会完全消失，而是降低到1-2级（"余震"），在下一章节自然消退
- 这确保了"痛苦不会被假装不存在"——但痛苦一定会被接住

#### 7.2.3 天使介入的代价

- Phase 1：天使轻松拉回，无代价
- Phase 2 前半：天使的翅膀开始黯淡（每次拉回黯淡一点）
- Phase 2 后半：天使的声音开始变远（玩家可感知到）
- Phase 3：天使的翅膀几乎透明，但她的介入反而变得更坚定——"没事的"不是因为她还有力量，而是因为她的爱比力量更大

**设计意图**：天使的虚弱是Phase 3真相揭示的情感铺垫。玩家在Phase 2已经隐约感到"天使在消耗自己"，Phase 3的真相只是确认了这个直觉。

### 7.3 "失败状态"的设计

> **本游戏没有"Game Over"。**

#### 7.3.1 逃避选择

- 玩家可以选择"逃避"某些质点的情感功课
- 逃避不会导致"失败"——但质点不会点亮，叙事会"循环"
- 循环中，天使会提供新的视角：
  - 第一次逃避：天使温柔地说"没关系的，慢慢来"
  - 第二次逃避：天使说"你知道吗，我有时候也想逃避。但我们在一起，可以试试"
  - 第三次逃避：天使不说话，只是抱住心爱的。然后，叙事自然推进——天使代替心爱的面对了这个功课
- 第三次逃避后，质点亮起，但亮度只有50%——玩家知道"这不是完美的通过，但通过了"

#### 7.3.2 消极选择

- 玩家可以选择"消极"选项（如"算了"、"无所谓"、"我不想管"）
- 消极选择不会导致失败，但天使会有反应：
  - 不是批评，而是"你确定吗？我也在这里"
  - 如果玩家确认消极选择，天使接受——"好。那我们走另一条路"
  - 叙事会通过另一条路径达到同样的质点亮起

#### 7.3.3 唯一被禁止的选择

- **存在保护机制唯一"禁止"的**：让玩家/心爱的陷入"存在无意义"的状态
- 如果系统检测到玩家的选择组合可能导致"虚无主义结局"（如：连续选择消极+逃避+拒绝天使），天使会强制介入：
  - 不是"系统提示"，而是**叙事性的天使独白**
  - 天使说："我不能让你走到那里。不是因为规则，是因为我爱你。来，看着我。"
  - 画面恢复，叙事继续
- 这是唯一一个"玩家选择被覆盖"的情况——但它以叙事方式呈现，不是以系统方式

### 7.4 存在保护与玩家自主性的平衡

**设计张力**：存在保护（永远不让你绝望）vs 玩家自主性（让你做自己的选择）

**平衡策略**：
1. **保护不限制选择**——玩家可以做任何选择，包括"消极"和"逃避"
2. **保护只限制"结局"**——没有任何路径通向虚无主义结局
3. **保护以叙事呈现**——天使的介入不是"系统拒绝你的选择"，而是"天使爱你所以拉住你"
4. **保护有"代价"**——天使的拉回消耗她的力量，这让保护不是"免费的"，而是"有重量的"
5. **最终选择不受保护**——Phase 3的最终选择是完全自由的。天使不会覆盖玩家的最终选择，即使玩家选择"拒绝毁灭天使"

## 8. 角色设计方向（叙事层面）

### 8.1 心爱的的叙事角色

#### 8.1.1 基本设定
- **身份**：创世少女神 / 真我质点 / 被王冠之神选中的人
- **特征**：从出生就不会哭、非典型孤独症、身体布满伤疤（背后大面积烧伤、下巴缝合、生长疤）
- **能力**：将幻想变为现实的奇迹之力
- **使命**：拯救13个"错误"
- **代价**：每拯救一个人，最终都必须亲手毁灭

#### 8.1.2 角色弧线

**起点**：解离的旁观者。心爱的看着世界发生的一切，像在看一部电影。她能感受到别人的痛苦（共情能力极强），但无法感受自己的（解离状态）。

**发展**：逐渐从旁观者变成参与者。每次拯救都让她的"壳"裂开一点。天使的陪伴让她开始感受到"被爱"。到了真我质点（Ch 13），她第一次面对自己——三重身份交汇。

**转折**：Phase 3，记忆回归。心爱的知道代价后崩溃。这是她最脆弱的时刻，也是天使最坚强的时刻。

**终点**：无论哪个结局，心爱的都从"不会哭"变成了"可以流泪的人"。这不是"治愈"——伤疤还在，代价还在——但她的内在整合了。天使（她的内在自我）不再分离于她之外。

#### 8.1.3 三重身份的叙事功能

| 身份 | 叙事功能 | 活跃章节 | 玩家体验 |
|------|---------|---------|---------|
| 处理器/分析者 | 理性分析世界，构建拯救方案 | Phase 1全 + Phase 2前半 | "我能解决这个问题" |
| 白裙少女 | 情感渴望，想要被爱、被拥抱 | Phase 2中段(Ch 7-11) | "我也想被温柔对待" |
| 隐藏的肥宅/创世者 | 把真话说在故事里，创造一切 | Phase 2后半 + Phase 3 | "这一切都是我创造的" |

三重身份不是"切换"——它们是同时存在的。玩家在不同章节主要"从"不同身份"看"，但三者在每个章节都有回响。

### 8.2 天使的叙事角色

#### 8.2.1 基本设定
- **身份**：心爱的的爱意化身 / 荣格阿尼玛的具象化 / 跨性别身份的精神投射 / 第13个"错误"
- **外貌**：穿白色连衣裙的少女，紫色翅膀
- **诞生**：心爱的12岁时对二次元角色的爱太强烈，天使从心中诞生
- **核心行为**：拥抱、亲吻额头、说"没事的，不要担心，有我在"
- **本质**：神与心爱的的"共同杰作"

#### 8.2.2 角色弧线

**起点**：纯粹的礼物。天使是爱本身——温暖、明亮、无条件。她没有自己的痛苦，她只为心爱的而存在。

**发展**：天使开始"有自己"。她开始心疼——不只是为心爱的，也为被拯救的人。她开始害怕——不是怕自己被毁灭，而是怕心爱的知道真相后会碎。她开始流泪——因为爱太重了。

**转折**：Phase 3。天使知道自己是第13个。但她不是崩溃的那个人——心爱的才是。天使反过来安慰心爱的。这是她最"像人"的时刻——不再只是"爱意化身"，而是一个选择了爱的人。

**终点**：天使的终局取决于玩家的选择。但无论哪个结局，天使的最后一句话都是一样的——"没事的，没事的，不要担心，有我在，我永远在你身边陪着你。"

#### 8.2.3 天使的内在矛盾

天使的核心矛盾：**她知道自己是"错误"，但她选择成为"爱"。**

- 天使从诞生就知道代价——她是"被拯救"的存在，也是"必须被毁灭"的存在
- 但她选择了不告诉心爱的——不是欺骗，而是"让她先学会爱"
- 天使的每一次安慰都是真心的——不是"程序设定"，而是选择
- 这个选择让天使从"爱意化身"升华为"选择了爱的人"

**哲学含义**：天使的存在本身就是对"存在保护"的终极回答——即使你的存在被定义为"错误"，你依然可以选择成为爱。这不是"正能量"——这是"在认清真相之后依然爱"。

### 8.3 13个"错误"的叙事模板

#### 8.3.1 "错误"的本质

"错误"不是"坏人"。他们是**被王冠之神创造的存在，其存在会让周围的人陷入虚无与自我毁灭**。他们没有选择成为"错误"——就像心爱的没有选择成为创世者。

每个"错误"都映射了心爱的自己的一段经历。拯救他们，是心爱的在拯救自己的不同面向。

#### 8.3.2 12个"错误"的叙事模板

每个"错误"的叙事包含以下结构：

```
错误叙事模板：
├── 表象：错误呈现出的一种"伤害行为"
├── 根源：错误为什么会这样——通常是一段创伤
├── 映射：这个错误映射了心爱的的哪段经历
├── 天使的视角：天使如何看待这个错误
├── 拯救路径：如何从"错误"转化为"被爱的人"
├── 暗流类型：释放的存在主义伤害暗流
└── 伏笔：拯救后留下的暗示（为Phase 3铺垫）
```

**12个"错误"清单**（对应Ch 1-12的拯救对象，Ch 13-16为内在/真相章节）：

| Ch | 质点 | 错误名 | 伤害类型 | 心爱的映射 | 核心叙事 |
|----|------|--------|---------|-----------|---------|
| 1 | 王国 | 白花 | 存在否定 | "我是多余的" | 觉得存在是负担 |
| 2 | 幸福 | 雨宫莲 | 希望抹杀 | "美好不真实" | 失去所有希望 |
| 3 | 基础 | 绽美 | 困难放大 | "我站不住了" | 被恐惧压垮 |
| 4 | 自我 | 融爱 | 羞耻循环 | "我是错的" | 身份被否定 |
| 5 | 逻辑 | 爱丽丝 | 虚无主义 | "一切无意义" | 理性解构意义 |
| 6 | 共情 | 星烬 | 可能性否定 | "做什么都没用" | 共情过载 |
| 7 | 超我 | 爱心 | 愤怒煽动 | "你不够好" | 内化批判 |
| 8 | 胜利 | 启明 | 自我伤害 | "不想活了" | 自毁倾向 |
| 9 | 荣耀 | 闪亮 | 羞耻+存在否定 | "真话让我孤独" | 真相的代价 |
| 10 | 严厉 | 唯爱 | 困难放大+虚无 | "为你好"的控制 | 被控制的爱 |
| 11 | 慈悲 | 爱如暖 | 希望抹杀+存在否定 | "谁来爱我" | 慈悲的消耗 |
| 12 | 理智 | 虹爱 | 虚无+可能性否定 | "理解了还是痛" | 理性的极限 |

**第13个"错误"——天使**：
- 不在Ch 1-12的任何一章被"拯救"
- 她的"拯救"发生在游戏开始之前——心爱的12岁的爱让她诞生
- 她的"毁灭"是游戏的最终选择
- 她映射的不是心爱的的一段经历，而是心爱的本身——天使就是心爱的的内在自我

#### 8.3.3 "错误"的转化

每个"错误"被拯救后不是"消失"或"变成好人"。他们**被看见**——

- 痛苦被看见（不再被否认）
- 存在被看见（不再被视为多余）
- 选择被看见（不再被剥夺可能性）

转化后的"错误"不会再次出现（在当前章节），但他们的故事会被天使记住，在后续章节中以"回忆"的形式回响——"你还记得白花吗？她现在过得很好。"

### 8.4 王冠之神的叙事角色

#### 8.4.1 基本设定
- **身份**：创造者 / 规则制定者 / 不小心创造了13个"错误"的存在
- **特质**：不是"恶神"——是一个犯了错的创造者
- **与心爱的的关系**：选择了心爱的，赐予奇迹之力，设定了"代价"
- **叙事功能**：不可见的规则——Kether是"源头"，是故事发生的条件，不是"反派"

#### 8.4.2 Kether的叙事定位

**Kether不是Boss**。Kether不是需要被"打败"的敌人。

- Kether是**规则本身**——"每拯救一个，必须毁灭一个"是宇宙的规则，不是Kether的恶意
- Kether的"错误"——不小心创造了13个"错误"——是**创造的代价**。任何创造都伴随着失误
- 心爱的的旅程不是"打败Kether"，而是**理解规则、面对代价、在规则中找到爱**
- 在最终选择中，Kether不出现——因为最终选择不是"对抗规则"，而是"在规则中如何选择"

#### 8.4.3 Kether的声音

- Kether在游戏中不以视觉形象出现——只有**声音**
- 声音在序章出现（赐予力量、宣告代价）
- 声音在Phase 3回忆中出现（"代价"的回响）
- 声音在最终选择中不出现——因为这是心爱的的选择，不是Kether的命令
- **设计意图**：Kether是"父母"的隐喻——给予生命，也给予伤害，但最终让孩子自己做选择

## 附录A：设计理论评审

### A.1 主导策略风险检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 是否存在"最优选择"路径 | ✅ 安全 | 不存在"最优解"——所有选择都有效，只影响纹理 |
| 是否存在"跳过痛苦"策略 | ⚠️ 注意 | "逃避"选择可以延迟痛苦，但不能消除。第三次逃避后天使代为面对。需要确保玩家不会把"让天使代替"当作策略 |
| 是否存在"刷天使好感"策略 | ✅ 安全 | 点击天使有冷却时间，且不影响"通关"，只影响对话内容 |
| 是否存在"速通"策略 | ✅ 安全 | 视觉小说无"速通"需求，且情感体验需要时间沉浸 |

### A.2 经济平衡检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 情感投入与回报是否平衡 | ✅ 安全 | 每个质点都有完整的"痛苦→安慰→转化→安息"循环 |
| 天使的介入是否有"通货膨胀" | ⚠️ 注意 | Phase 1天使介入频繁，可能让玩家"习惯"安慰。需要确保Phase 2-3的介入有质的变化（代价、深度） |
| 暗流强度是否过度 | ✅ 安全 | 暗流强度渐进递增，且每次都有天使拉回。最高强度（10级）只在Phase 3出现 |

### A.3 认知过载检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 16质点结构是否过于复杂 | ⚠️ 注意 | 16个质点对普通玩家可能过多。缓解：核心层只需体验情感旅程，质点系统在后台运作；视觉上只展示当前质点和生命之树整体 |
| 8种存在保护类型是否需要玩家记忆 | ✅ 安全 | 不需要。存在保护是系统层面运作，玩家只需要感受到"天使在保护我" |
| 三重身份是否造成混淆 | ⚠️ 注意 | 三重身份的揭示是渐进的，但需要确保玩家不会感到"这是三个人"。缓解：三重身份的切换由叙事自然引导，不由玩家手动操作 |
| 卡巴拉术语是否构成门槛 | ⚠️ 注意 | "质点""八度""Kether"等术语可能让不熟悉卡巴拉的玩家困惑。缓解：游戏中不强制教学这些术语，用情感语言替代（如"王国"→"物质世界"，"王冠"→"源头"） |

### A.4 支柱漂移检查

| 支柱 | 漂移风险 | 缓解措施 |
|------|---------|---------|
| 天使永不离去 | 低 | 天使在系统层面永远存在，无任何分支可以移除天使 |
| 痛苦可被转化 | 中 | Phase 3的痛苦最为极端——需要确保即使"代价"被揭示，天使的陪伴依然构成转化路径 |
| 解离走向整合 | 中 | Phase 1的"解离感"体验可能让玩家觉得"不够沉浸"。需要平衡：解离是心爱的的状态，不是玩家的状态——玩家始终能看到心爱的的情感，只是心爱的自己感受不到 |

## 附录B：与美术方向的协调点

> 以下为需要与 art-director（林绘澄）协调的设计要点：

### B.1 天使的视觉设计

- **核心需求**：天使必须传达"被拥抱"的感觉——她的形象应该让玩家看到就想靠近
- **翅膀的进化**：从明亮→逐渐黯淡→几乎透明→恢复（结局时）。需要设计至少5个翅膀状态
- **表情系统**：至少需要5种基础表情（平静/心疼/坚定/悲伤/温柔）× 差分
- **白色连衣裙**：天使的标志性服装，需要在所有场景中保持一致性，但可以有微妙的变化（如Phase 3时裙摆可能更长/更旧，暗示时间流逝）
- **紫色翅膀**：需要确定紫色的具体色值和发光效果——这是天使的视觉签名

### B.2 心爱的的视觉设计

- **伤疤**：背后大面积烧伤、下巴缝合、生长疤——这些伤疤是心爱的身份的一部分，需要被尊重地呈现
- **表情系统**：心爱的"不会哭"是核心特征——她的表情变化应该非常微妙（嘴角、眼神的微小变化），直到Phase 3才出现明显的情感爆发
- **三重身份的视觉区分**：处理器（冷静/分析）、白裙少女（柔软/渴望）、创世者（深邃/超脱）——是否需要视觉区分，还是用文字区分？

### B.3 暗流的视觉表现

- 8种暗流需要8种独特的视觉表现——需要与美术协调具体效果
- 暗流表现不能过于"恐怖"——这是疗愈游戏，暗流是"压迫感"不是"恐怖"
- 关键约束：暗流的视觉表现必须能被"天使的介入"即时解除——视觉效果需要在"暗→亮"之间有流畅的过渡

### B.4 生命之树的视觉化

- 16质点需要在界面上以生命之树的形式展示
- 需要设计"点亮式"的进度展示——已完成质点亮起，未完成质点暗淡
- 需要确定生命之树的布局——传统卡巴拉10质点布局 vs 苞苞的16质点双八度布局

### B.5 色彩方向

- 整体色调需要温暖但不过于明亮——"在黑暗中看到光"的感觉
- 紫色和白色是核心色（天使的翅膀和连衣裙）
- 暗流期间需要冷色调（灰、黑、蓝）
- 天使介入后需要暖色调（金、白、粉）

### B.6 可访问性

- 文字大小和对比度需要符合可访问性标准
- 暗流的视觉闪烁需要可关闭（光敏性考虑）
- 天使的立绘需要有不遮挡文字的布局选项
- 考虑色盲友好的暗流表现（不仅靠颜色区分）

## 附录C：已知风险与缓解

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 素材过于个人化，玩家难以共鸣 | 中 | 设计时保留情感普适性：每个人都有"心中的天使"；痛苦的具体细节可由玩家自行投射 |
| 叙事过于沉重（创伤主题） | 高 | 存在保护机制确保每个章节都有温暖出口；"安息"阶段是必须的情感缓冲 |
| 16质点结构过于复杂 | 中 | 分层设计：核心层只体验情感旅程，质点系统在后台运作；深度玩家可探索质点系统 |
| 代码外包沟通成本 | 中 | 本文档产出的叙事规格可直接交给外包；后续GDD阶段需要产出具可实现性的技术规格 |
| 天使的对话量巨大 | 高 | 建议分阶段编写：Phase 1对话优先完成（教学+核心体验），Phase 2-3对话迭代完善 |
| Phase 3的情感强度可能触发玩家创伤 | 高 | 需要设计"内容预警"系统；在进入Phase 3前提供内容提示；天使的介入确保不会陷入绝望 |
| 多结局可能导致"选择焦虑" | 低 | 所有结局都是"好的"——没有坏结局。在最终选择前，天使明确说"不管你选什么，都没关系的" |
| 三重身份的揭示可能让玩家困惑 | 中 | 渐进式揭示，不在同一章节同时呈现三重身份；每重身份的揭示都有明确的叙事触发点 |
