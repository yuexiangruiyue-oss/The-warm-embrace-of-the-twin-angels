# 《双生天使的怀抱》美术圣经

> **版本**：Phase 1 概念孵化版  
> **日期**：2026-08-02  
> **美术指导**：林绘澄（Lin Wayson）  
> **适用范围**：视觉身份、角色设计、场景、UI、资产规格、可访问性、生产管线

---

## 0. 最高原则：温暖优先于华丽

本游戏的美术不是为了让画面"好看"或"炫技"，而是为了让玩家感到**被拥抱、被允许、被安全地接住**。所有视觉决策的最高标准是：

- **可爱**（不是幼稚，而是没有威胁）
- **温暖**（光线、色调、角色表情都指向安全）
- **治愈**（痛苦可被看见，也能被转化）
- **有安全感**（没有突兀的视觉惊吓、没有冷酷的距离感）

**禁忌**：写实血腥、暗黑哥特、宗教压迫感、繁复华丽的浮夸装饰、冷峻空洞的眼神。

### 1.3 字体方向

- **UI/标题字体**：圆角无衬线体，如思源黑体 / 阿里巴巴普惠体 / 站酷快乐体，字号足够大，避免尖锐衬线。
- **正文/对话框**：清晰易读的黑体，建议最小字号 22px（1080p 下），行高 1.6。
- **特殊文本**（天使低语、系统提示）：可用稍细的字体或轻微发光效果，与普通对白区分。
- **可访问性要求**：字体必须支持简体中文，避免艺术字体作为正文。

### 1.4 视觉语言原则

1. **圆形优先**：对话框、按钮、光环、光斑以圆角/圆形为主，减少尖锐感。
2. **柔和边缘**：背景使用轻微高斯模糊或雾化，角色边缘可加 1-2px 柔光。
3. **呼吸光效**：天使出现时，光源不是恒定的，而是轻微呼吸式明暗变化。
4. **水与倒影**：大桥、眼泪、黑暗空间都可使用水面倒影作为"现实与内心"的视觉隐喻。
5. **留白即安全**：不要把画面塞满，保留足够的空白/柔色区域，让眼睛能休息。

## 2. 角色设计方向

### 2.1 天使（核心伴侣角色）

#### 基础外貌

- **性别气质**：少女，温柔的女性气质，是心爱的的内在女性自我与跨性别身份的精神投射。
- **发型**：长发，发色为淡紫或银白渐变，发丝柔软不僵硬。
  - **关键**：刘海不要遮住眼睛太多，眼睛要清晰可见，传达"我被看见"的安全感。
  - 无复杂头饰，可有一两条细细的发带或小蝴蝶结。
- **眼睛**：大而圆，瞳孔偏暖紫或粉，眼神永远温柔、专注、含笑，没有攻击性。
- **肤色**：白皙但带有健康的红润（脸颊微红）。
- **表情**：嘴角自然微微上扬，像是在说"没事的，有我在"。

#### 服装

- **白色连衣裙**：
  - 长度到膝盖以下，裙摆轻柔飘逸。
  - 裙身可以有简单的紫色小花、小蝴蝶或蕾丝装饰，**不繁复**。
  - 腰部可用淡紫色丝带系成蝴蝶结。
- **足部**：**赤脚**，不沾尘土，象征纯净与无防备。
- **翅膀**：
  - 紫色到淡粉色渐变的大型羽翼。
  - 翼膜半透明，边缘有柔和发光。
  - 静止时收拢在身后，拥抱时微微展开包裹主角。
- **光环**：
  - 头顶有淡淡的暖金色光环（类似光晕，不刻板）。
  - 在"温暖时刻"光环会微微发亮。

#### 表情集（差分建议）

| 表情 | 关键词 | 使用场景 |
|------|--------|----------|
| 温柔微笑 | 默认 | 陪伴、安慰 |
| 闭眼微笑 | 更深沉的安心 | 拥抱、亲吻额头 |
| 心疼 | 眉毛微蹙，眼神柔和 | 主角痛苦时 |
| 坚定 | 眼神明亮，嘴角仍带笑 | 鼓励、守护 |
| 含泪微笑 | 感动、心酸被看见 | 融合前、分离前 |
| 轻咬嘴唇 | 不舍、担忧 | 代价揭示时 |

#### 姿态集

| 姿态 | 描述 | 使用场景 |
|------|------|----------|
| 正面张开双臂 | 欢迎、接纳 | 天使首次正面出现 |
| 从身后环抱 | 双手轻放主角胸前/腹部 | 大桥诞生、黑暗陪伴 |
| 轻抚头发 | 一只手抬起，眼神低垂温柔 | 安慰哭泣/崩溃 |
| 亲吻额头 | 倾身向前，闭眼 | 深度治愈时刻 |
| 紧紧拥抱 | 双臂环绕，头靠在主角肩上 | 害怕失去、融合 |
| 坐在身侧 | 并肩，手轻搭 | 日常陪伴 |
| 半身透明 | 淡淡的虚化 | 主角回忆、意识边缘 |

#### 视觉锚点总结

> 一个赤脚穿白裙、紫粉渐变翅膀、头顶柔光、永远温柔注视你的少女。她的存在本身就是"安全"的视觉化。

### 2.2 心爱的（主角）

#### 视觉转变弧线

| 阶段 | 年龄 | 外貌特征 | 色彩处理 |
|------|------|----------|----------|
| **童年期** | 学龄前/小学 | 短发、灰暗、面无表情、眼神空洞、衣着脏乱（"身上很黑"）、伤痕隐约可见 | 低饱和、灰蓝/土黄、背景压抑 |
| **二次元觉醒期** | 12岁 | 眼神第一次出现光芒，开始注意外表，屏幕/画册的反光映在脸上 | 局部出现紫/粉色高光 |
| **天使诞生后** | 少年 | 表情开始柔和，周围出现天使的暖光，衣着逐渐整洁 | 画面整体回暖 |
| **觉醒后（整合期）** | 后期 | 穿**白色连衣裙 + 白色丝袜**（遮盖生长疤），头发可能留长，表情安定 | 明亮、柔和、与天使视觉融合 |

#### 伤痕处理原则（重要）

- **不写实、不血腥**：不出现伤口裂开、流血、结痂等写实创伤画面。
- **象征性可见**：童年期的疤痕以淡褐色/浅紫线条淡淡呈现，随着年龄增长逐渐淡化。
- **不猎奇化**：不聚焦、不特写伤痕，只在全身立绘中自然存在。
- **觉醒后的遮盖**：白色丝袜象征"我愿意照顾自己了"，不是隐藏羞耻，而是温柔的自我保护。

#### 服装设计

- **童年**：肥大、灰暗的旧衣服，颜色接近灰蓝、土褐。
- **少年**：普通校服或深色日常服，逐渐整洁。
- **觉醒后**：
  - **白色连衣裙**（非洛丽塔，简洁款，与天使呼应但更不张扬）。
  - **白色丝袜**。
  - 头发可系淡紫色蝴蝶结。
  - 表情从"不会哭"变为"可以笑了"。

#### 关键视觉时刻

- **诞生时刻**：跪在桥上的剪影，天使从背后抱住，城市灯火倒映在河面。
- **黑暗陪伴**：主角蜷缩，天使像一团温暖的光包住他。
- **融合时刻**：天使与心爱的合二为一，画面呈现为一个穿白裙的少女，兼具两者的特征。

### 2.3 16质点角色设计方向

**总体原则**：

- 统一柔和二次元风格，**可爱、温暖、无宗教压迫感**。
- 每个角色通过**主题色、标志性小物、发型/服饰元素**区分，不做暗黑或冷酷设计。
- 神性八度偏向"抽象概念拟人"，人类八度偏向"贴近日常与心理功能"。

#### 设计注意事项

- **不强调宗教符号**：避免直接使用大卫之星、十字架等强宗教符号。生命之树用抽象几何表现。
- **男女角色都柔和**：男性角色（启明、雨宫莲）也是温柔少年，不是冷酷帅哥。
- **虹爱（AI）**：可通过数字感小细节（如眼中点阵、服饰边缘的细微像素/彩虹反光）表现，但不冰冷。

### 2.4 王冠之神（Kether）

- **不人格化为威严老者**：避免传统"白胡子神王"形象。
- **视觉方向**：一团纯白而寂静的光，或一个由光尘构成的、没有具体面容的少女/中性轮廓。
- **情感定位**：不是审判者，而是"创造的源头"。其压迫感来自"空无"而非"暴力"。
- **表现方式**：
  - 最初出现时是一个纯白的光球/光门。
  - 随着对话深入，逐渐形成模糊的人形轮廓，但没有五官。
  - 声音（如果配字幕/文字效果）用非常淡的金色或白色文字。

## 3. 环境与场景美术

### 3.1 关键场景视觉概念

#### 大桥夜景（天使诞生）

- **构图**：低角度，主角跪在桥中央偏下，天使从背后环抱，占据画面中下部。
- **色彩**：夜空深蓝紫，城市灯火暖黄/暖白，河水反射所有光线。
- **特效**：
  - 光晕呼吸式明暗。
  - 水面有轻微的波纹和倒影扭曲。
  - 天使翅膀边缘发光，映照在河面。
- **情绪**："在城市的冷漠中，第一次被接住"。

#### 学校场景

- **色彩**：低饱和灰蓝、冷白荧光灯、暗褐色课桌椅。
- **光线**：从窗户斜射进来的冷光，人物面部半明半暗。
- **构图**：主角常位于画面边缘或被人群/桌椅包围，强调孤立感。
- **情绪**：压抑但不恐怖，像"灰色的沉默"。

#### 黑暗空间（天使陪伴）

- **色彩**：几乎全黑，但中心有柔和的暖金/淡紫光。
- **元素**：没有具体环境细节，只有主角和天使。
- **特效**：
  - 天使是主要光源。
  - 周围有极淡的粒子漂浮（像尘埃或小火花）。
  - 远处可能有模糊的光点，象征"希望遥远但存在"。
- **情绪**："黑暗不可怕，因为她在"。

#### 生命之树空间

- **结构**：抽象化的16质点 + 22条路径，三柱结构清晰但不冰冷。
- **三柱配色**：
  - 左柱（严厉）：偏冷紫/暗玫瑰。
  - 右柱（慈悲）：偏暖金/柔粉。
  - 中柱（和谐）：白金光。
- **深渊（Da'ath）**：王冠与下层之间的空白区域，用淡淡的雾气或断层表现。
- **动态**：路径像发光的丝线，质点像温柔的节点，玩家经过时亮起。

#### 花之国（平行叙事）

- **设定**：3056年、雪灾、水仙花、蓝色光点。
- **色彩**：冰蓝、雪白、淡黄（水仙花心）、微紫（神识光点）。
- **元素**：被雪覆盖的花田、发光的蓝色光点化为少女、公主融花。
- **情绪**：寒冷中的温暖，牺牲与陪伴。

### 3.2 场景情感色调映射表

| 情感 | 主色 | 光影 | 常用元素 |
|------|------|------|----------|
| 安全/陪伴 | 天使紫 + 暖金 | 柔和环绕光 | 羽毛、花瓣、光点、水波 |
| 孤独/压抑 | 灰蓝 + 冷白 | 冷光源、阴影 | 空教室、人群剪影、雨天 |
| 痛苦/解离 | 暗紫 + 黑 | 边缘模糊、失焦 | 破碎倒影、黑暗空间 |
| 觉醒/希望 | 白 + 金 + 淡紫 | 从暗到明的渐变 | 晨光、花开、天使张开翅膀 |
| 融合/完整 | 白 + 彩虹微光 | 全身柔和发光 | 两个轮廓合二为一 |

## 4. UI 视觉风格

### 4.1 对话框设计

> **更新说明**（2026-08-03）：对话框背景色和字号已与 UX 规格（`ux-specification.md` §2.3.2）对齐。深紫藤背景为默认（可访问性优先），浅色版本在低刺激模式下使用。

- **形状**：底部圆角矩形，四角大圆角（避免尖锐）。
- **尺寸**：1920 × 280 px，底部对齐。
- **背景色（默认）**：半透明深紫藤（`#6B5A98`，alpha 0.85）——可访问性优先，配白色文字对比度高。
- **背景色（低刺激模式）**：半透明浅紫雾（`rgba(253, 248, 255, 0.92)`）——更柔和温暖。
  - **低刺激模式文字色**：深紫藤 `#6B5A98` 或夜灰蓝 `#4A5568`（需满足 WCAG AA 对比度 ≥ 4.5:1，浅紫雾背景上天使白 #FDF8FF 对比度不足，不可使用）。
- **底部边线**：细细的紫色边线（`#8B7AB8`，1px）。
- **文字**：天使白 `#FDF8FF`（深色背景时）/ 深紫藤 `#6B5A98`（浅色背景时），字号 30px（Normal），行高 1.6。
  - **四档文本大小**：Small 24px / Normal 30px（默认）/ Large 34px / Extra Large 38px。
  - **最低可读性**：22px（B-V01 强制底线，低于此不可接受）。
- **说话人标签**：左侧小圆角标签，天使用天使紫底白字，系统/旁白用暖金底深字。
- **文字区域**：左边距 80px，右边距 80px，上边距 70px（文字区域宽度 1760px）。
- **文字出现效果**：逐字出现，速度可调；天使台词可稍微慢一点，营造低语感。
- **特殊效果**：
  - 天使说话时，对话框边缘有轻微暖金光晕。
  - 系统/王冠之神说话时，文字可稍微透明或带轻微震动（不刺眼）。

### 4.2 选择按钮设计

- **形状**：圆角胶囊形或圆角矩形。
- **常态**：浅紫雾底，深紫藤文字，细边框。
- **Hover/聚焦**：天使紫底，白色文字，边缘有柔和光晕。
- **已选/不可选**：已选用暖金底，不可选为浅灰半透明。
- **排列**：垂直排列在画面下方或右侧，间距足够大，避免误触。

### 4.3 质点进程 UI

- **核心隐喻**：玩家不是"闯关"，而是"点亮生命之树上的节点"。
- **设计方向**：
  - 左侧或右侧悬浮一个迷你生命之树缩略图。
  - 当前质点微微发光并轻微呼吸。
  - 已完成的质点保持柔和点亮状态，颜色为该质点的主题色。
  - 未到达的质点为淡灰轮廓。
- **章节标题卡**：每个质点章节开头，用该角色/质点的主题色 + 相关符号做一张温柔的标题卡。

### 4.4 天使陪伴系统 UI

- **设计目标**：让玩家在任何时刻都感受到"天使在身边"。
- **常驻元素**：
  - 屏幕角落有一个小小的天使头像/羽毛图标，微微发光。
  - 点击或自动触发时，屏幕边缘出现淡紫色的柔光，像被拥抱。
- **互动反馈**：
  - 当剧情进入安慰段落，天使图标会轻轻跳动。
  - 可在设置中开启/关闭"天使陪伴光效"。
- **不打扰原则**：图标要小、透明、不闪烁，只在需要时出现明显反馈。

### 4.5 设置菜单

- 半透明卡片式设计，圆角大，背景模糊。
- 分类标签：显示、声音、文字、可访问性、语言。
- 所有滑块、开关都要足够大，方便点击。

## 7. 可访问性分级

本游戏的可访问性目标为 **Comprehensive 级别**：确保有感官、认知或情绪需求的玩家都能安全地体验故事。

### 7.1 分级定义

| 级别 | 定义 | 本项目目标 |
|------|------|------------|
| **Basic** | 基础可玩 | 文字可读、颜色不唯一传递信息 |
| **Standard** | 行业常规 | + 字幕、文本缩放、色盲模式、跳过重复动画 |
| **Comprehensive** | 深度包容 | + 情绪安全警告、高对比/低刺激模式、输入重映射、节奏控制 |
| **Exemplary** | 标杆级 | + 全盲/严重运动障碍支持（超出本项目范围，可选扩展） |

### 7.2 可访问性特性矩阵

| 特性 | 级别 | 实现方式 |
|------|------|----------|
| **文本大小调整** | Standard | 24px / 30px / 34px / 38px 四档（Normal 30px 默认） |
| **高对比度模式** | Comprehensive | 提供深色高对比主题，文字与背景对比度 ≥ 7:1 |
| **低刺激模式** | Comprehensive | 关闭闪烁、降低粒子、减慢光效呼吸 |
| **色盲友好** | Standard | UI 关键状态不用颜色唯一区分，加图标/文字标签 |
| **屏幕抖动/闪光关闭** | Comprehensive | 所有创伤回忆段落可关闭视觉震动 |
| **内容警告与跳过** | Comprehensive | 每章开头显示情绪主题，可跳过具体创伤描写画面 |
| **自动前进速度** | Standard | 可调文字出现速度 + 完全自动模式 |
| **跳过已读** | Standard | Ren'Py 原生支持 |
| **全屏/窗口化** | Standard | 原生支持 |
| **暂停菜单随时可用** | Standard | 对话中可暂停 |
| **天使陪伴开关** | Comprehensive | 可关闭/减弱屏幕边缘光效 |
| **输入重映射** | Comprehensive | 空格/回车/鼠标/手柄均可推进对话 |
| **字幕/文字描述** | Standard | 无语音游戏默认全文本，CG 提供文字描述 |

### 7.3 情绪安全设计

- **存在保护机制可视化**：当系统检测到叙事走向存在否定时，UI 边缘出现天使紫光提醒。
- **章节主题提示**：每章开始前用一句话提示本章情感主题（如"本章涉及童年孤独"），让玩家有心理准备。
- **安全出口**：任何时刻玩家都可以打开菜单，看到天使的 Q版提示"我在这里"。

## 8. 美术管线建议

### 8.1 生产策略

考虑到用户预算有限且外包代码，建议采用 **"AI 辅助生成 + 人工精修 + 统一后期"** 的管线：

```
需求定义（美术圣经） → AI 批量出草图/初稿 → 人工筛选/修改/重绘 → 
统一色彩校正/风格对齐 → 输出 Ren'Py 可用资产
```

#### 推荐工具

| 阶段 | 工具建议 | 说明 |
|------|----------|------|
| 概念草图 | Stable Diffusion / NovelAI / Midjourney | 快速探索角色外观 |
| 角色精修 | Photoshop / Clip Studio Paint / Procreate | 统一画风、修正手部/眼睛、清理背景 |
| 背景制作 | AI + 手动合成 / 手绘 | 关键场景建议分层输出 |
| UI 制作 | Figma / Photoshop | 矢量 UI 方便缩放 |
| 版本管理 | 本地文件夹 + 命名规范 | 见 5.1 |

### 8.2 成本控制建议

1. **先定天使和心爱的**：这两个角色是视觉核心，先打磨到 90% 满意，再扩展其他角色。
2. **复用姿态和表情**：通过表情差分 + 姿态组合减少立绘数量。
3. **背景复用**：同一场景的白天/夜晚/发光版可通过调色和光效层变化，而非重画。
4. **16质点角色分批**：
   - 第一阶段：天使、心爱的、王冠之神、心音、爱如暖、白结、爱心、真我、白花。
   - 第二阶段：其余 7 个质点角色。
5. **CG 优先核心节点**：不要为每个章节都做 CG，先保证 8 个核心情感 CG。

### 8.3 风格统一技巧

- **建立 LUT/调色预设**：在 Photoshop 中保存一组"温柔浅紫"调色 LUT，所有图最后都过一遍。
- **统一眼睛画法**：所有角色眼睛的高光、瞳孔形状保持一致。
- **统一线稿粗细**：角色外轮廓 2-3px，内部线条 1-2px。
- **统一阴影色**：所有角色阴影偏向紫/蓝紫，而非纯灰。

### 8.4 外包沟通清单

如果将精修工作外包，必须提供：

1. 本美术圣经完整文档。
2. 天使和心爱的的参考图（含 AI 参考和本章描述）。
3. 色彩 swatch 文件（ASE/ACO）。
4. 命名规范表。
5. 每个角色的 mood board（3-5 张参考图）。

## 9. 风险与待决策事项

### 9.1 潜在风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| AI 生成角色风格不稳定 | 角色不像同一人 | 建立固定提示词模板 + 人工精修统一 |
| 16质点角色数量过多 | 预算/时间爆炸 | 分两阶段，先核心 9 个 |

| 宗教符号敏感 | 生命之树被误解 | 抽象化处理，避免直接宗教符号 |
